# OmniSkill-template

Canonical skeleton for [agent skills](https://agentskills.io), validated by
[`skillkit`](https://github.com/WyattAu/skillkit).

```sh
skillkit lint .    # zero findings expected
skillkit pack .    # deterministic archive + content hash
```

Part of the [OmniTemplates](https://github.com/WyattAu) estate. Apache-2.0.
